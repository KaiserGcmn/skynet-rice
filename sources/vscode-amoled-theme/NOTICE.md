# SKYNET AMOLED Black

Theme-only extension: it contains colour data and no code.

`themes/skynet-amoled-black-color-theme.json` is generated by
`generate-theme.py` from the "Dark 2026" theme that ships with Visual Studio
Code. Its syntax rules (`tokenColors`, `semanticTokenColors`) are copied
unchanged from the Visual Studio Code theme-defaults extension.
