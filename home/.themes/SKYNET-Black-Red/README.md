# SKYNET Black Red

GTK 3/4 adaptation of Graphite GTK Theme by vinceliuice, licensed GPL-3.0;
see COPYING.

Upstream: https://github.com/vinceliuice/Graphite-gtk-theme
Commit: 2a8dd5aa1346d77539bf8196061260f353ee8d75 (2026-08-23 release)
Archive SHA-256: a07b6a78af315a6d33a49108839bed0e8232cb367ff0c6a658ce22cc99665e63

SKYNET changes: pure #000000 background/surface/sidebar, #d32f2f red
accent, compact spacing, normal sidebar and 4px base corners.
GTK 2 uses a small compatibility style on the installed Adwaita-dark theme.
GNOME Shell, GDM and window-manager themes are not included.
Only CSS-referenced assets are retained. Existing cursor and icon themes
are kept. The customization patch is sources/gtk-skynet/graphite-skynet.patch
in the skynet-rice repository; see docs/GTK-THEME.md for rebuild/rollback.
